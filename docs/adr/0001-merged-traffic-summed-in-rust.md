# Merged Traffic is summed in Rust, in the same frame as each device's traffic

Merged Traffic used to be summed in the panel from the device cards' views, because the Rust merge returned only per-peer views ("totals across devices are their sum, taken where the views are shown"). That left Traffic metrics derived in three places — the local log reader, the peer merge and the panel — so each new metric touched six to ten files. We now sum in one Rust module: it decides which view stands for each device (this device once, the forwarded device's live view over its peer summary, duplicates excluded), lines their buckets up by time, and streams every device's traffic together with Merged Traffic in one frame. The panel only renders, and Merged Traffic always equals the sum of the cards because both come from the same frame.
